# 春秋（Spring and Autumn）

> 一款从零自研的 2D 平面即时策略对战游戏，背景设定在春秋时期。目标是不依赖任何商业游戏引擎，打造一个注重公平竞技、具备多层级征服与历史演进机制的纯策略游戏。

---

## 📖 项目简介

本项目是一个个人长期实践项目。游戏的灵感来源于《大秦帝国》与《红警》的结合——我们希望剥离重度氪金与数值碾压，保留招募与养成乐趣，将核心聚焦于**“古代战场模拟 + 即时战术操作 + 绝对公平竞技”**。

游戏从春秋乱世开局，玩家需要通过铺路、占领、经营、招募，逐步扩张势力，最终实现区域乃至全国的征服。随着时代的发展，游戏机制将随文明的发展质量而动态演进。

---

## ✨ 核心特性与进度

目前项目已经完成了**基础框架与核心策略循环**的搭建：

- [x] **底层架构**：逻辑与渲染彻底分离，`logic/` 层完全不依赖 SDL，保证底层计算的纯净与高效。
- [x] **无头测试模式**：支持无窗口极速批量模拟，内置多策略 AI（随机、激进、稳健），用于自动化平衡性测试。
- [x] **格子化地图**：100x100 网格地图，支持摄像机平滑移动、缩放、坐标转换。
- [x] **铺路与占领机制**：部队只能从己方领地出发，一格一格推进，停留 2 秒完成占领，重现“一寸一寸争夺”的战略感。
- [x] **经济与建造**：木材、铁矿、粮草产出，大营、兵营、伐木场、铁矿场等建筑系统。
- [x] **招募与武将系统**：包含武将（武力、统率）、名士（智力、口才）、招贤令抽卡、名士阁寻访、招降机制。
- [x] **战斗系统**：简化的格子遭遇战，支持攻击力、血量、死亡结算。

🚀 快速开始
环境要求
操作系统：Windows 10 / 11

IDE：Visual Studio 2026（需勾选“使用 C++ 的桌面开发”工作负载）

依赖库：SDL3 与 SDL3_ttf（需在项目属性中配置包含目录、库目录及 DLL 复制）

编译指南
克隆仓库至本地：

bash
git clone https://github.com/你的用户名/你的仓库名.git
使用 Visual Studio 打开根目录下的 Project2.sln。

顶部配置选择 Debug 或 Release，平台选择 x64。

点击“生成解决方案”（或按 Ctrl+Shift+B）。

运行方式
正常游玩：直接运行 Project2.exe。

鼠标操作：点击选中单位，右键移动/攻击/占领。

键盘快捷键：按 T 使用招贤令抽卡，按 V 派遣名士寻访，按 ESC 退出。

AI 自动测试：在命令行终端中运行 Project2_headless.exe --games 100。

自动跑 100 局 AI 对战，结果输出至 stats.log，详细行为输出至 ai_log.txt。

🎮 游戏机制概述
资源循环：大营提供基础产出，占领资源点并建造对应设施（伐木场等）可大幅提升效率。

武将获取：

新手池：开局免费抽取。

招贤令：通过占领资源点、完成任务获取，有每日/每周上限。

寻访：派遣名士前往特定地点，名士智力与口才越高，越容易发现高品质武将。

招降：攻破敌方城池后，有一定几率招降敌方武将。

战斗与克制：单位具有攻击力、攻速、血量。目前为简化版战斗，后续将加入兵种克制、地形影响与士气机制。

🤝 贡献与开发原则
由于这是一个自研引擎的个人实践项目，我们遵循以下开发原则：

核心逻辑纯净：logic/ 目录下的所有代码禁止包含任何 <SDL3/...> 头文件。

AI 驱动测试：任何核心数值或机制的修改，必须先在无头模式下跑通至少 100 局 AI 对战，确保无崩溃。

提交规范：欢迎提交 Issue 或 Pull Request。提交前请确保代码可以在 Debug | x64 下无警告编译通过。
