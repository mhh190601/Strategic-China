# 春秋（Spring and Autumn）

> 一款从零自研的 2D 平面即时策略对战游戏，背景设定在春秋时期。目标是不依赖任何商业游戏引擎，打造一个注重**公平竞技**、支持**局域网/多人联机**，并具备多层级征服与历史演进机制的纯策略游戏。

---

## 📖 项目简介

本项目是一个个人长期实践项目。游戏的灵感来源于《大秦帝国》与《红警》的结合——剥离重度氪金与数值碾压，保留招募与养成乐趣，将核心聚焦于**“古代战场模拟 + 即时战术操作 + 公平多人对抗”**。

游戏从春秋乱世开局，玩家需要通过铺路、占领、经营、招募，逐步扩张势力。最终目标是在局域网或服务器环境下，实现多名玩家同图争霸，靠实力与运气问鼎中原。

---

## ✨ 核心特性与进度

- [x] **底层架构**：逻辑与渲染彻底分离，`logic/` 层完全不依赖 SDL，保证底层计算的纯净与高效。
- [x] **无头测试模式**：支持无窗口极速批量模拟，内置多策略 AI，用于自动化平衡性测试。
- [x] **格子化地图与铺路**：100x100 网格地图，部队只能从己方领地出发，一格一格推进占领，重现战略感。
- [x] **经济与招募系统**：资源采集、建筑建造、武将/名士招募、招贤令机制。
- [x] **战斗系统**：简化的格子遭遇战，支持攻击力、血量、死亡结算。
- [ ] **联机架构支持（开发中）**：基于前期局域网战术版经验，正在将 `Project2` 的逻辑层重构为支持**主机权威（Host-Authoritative）**的模式，为后续的多端同步做准备。
- [ ] **局域网多人对战**：支持 2~4 名玩家在同一大地图上争霸，同步格子归属、资源产出、单位行军与战斗状态。

## 🛠️ 技术栈

- **开发语言**：C++17
- **多媒体库**：SDL3, SDL3_ttf
- **网络通信**：Winsock2 (UDP/TCP 预留)
- **构建与开发环境**：Visual Studio 2026 (MSVC)
- **开发辅助**：CodeBuddy (AI 编程助手)

├── main_graphic.cpp     # 图形模式入口
├── main_headless.cpp    # 无头批量测试模式入口
├── Project2.sln         # VS 解决方案文件
└── README.md
🚀 快速开始
环境要求
操作系统：Windows 10 / 11

IDE：Visual Studio 2026（需勾选“使用 C++ 的桌面开发”工作负载）

依赖库：SDL3 与 SDL3_ttf（需在项目属性中配置包含目录、库目录及 DLL 复制）

编译与运行
克隆仓库：

bash
git clone https://github.com/你的用户名/你的仓库名.git
使用 Visual Studio 打开 Project2.sln。

选择 Debug | x64 配置，生成解决方案。

正常游玩：运行 Project2.exe。

AI 批量测试：命令行运行 Project2_headless.exe --games 100。

🤝 贡献与开发原则
核心逻辑纯净：logic/ 目录下禁止包含任何 <SDL3/...> 头文件。

联机安全原则：未来实现联机时，必须遵循主机权威逻辑。客户端只发送指令，主机计算后广播状态，确保防作弊与公平。

AI 驱动测试：任何核心数值或机制的修改，必须先在无头模式下跑通至少 100 局 AI 对战，确保无崩溃。

🗺️ 未来路线图 (Roadmap)
□ 局域网联机 (1v1)：打通基础网络通信，复用 Project1 的经验，实现两台电脑同步格子占领与战斗。
□ 多人同图争霸 (2-4人)：扩展网络架构，支持多名玩家同时在一个地图上争夺城池，引入简单的外交/结盟机制。
□ 兵种与阵法：引入戈兵、车兵、弓手，加入战前阵法。
□ 时代演进系统：当统一特定区域后，根据评分解锁下一时代（如战国、秦）的科技与兵种。
□ 美术升级：用具备春秋风格的 2D 像素/水墨素材替换几何图形。
